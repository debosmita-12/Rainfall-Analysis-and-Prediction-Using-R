This folder contains the Week 1 project planning deliverable for the project **Rainfall Analysis and Prediction Using R**.

## Planned study
- Location: Kolkata, West Bengal, India
- Proposed period: 2016-01-01 to 2025-12-31 (confirm source coverage before final analysis)
- Planned source: Open-Meteo Historical Weather API
- Main variable: daily precipitation (mm; confirm definition and units in provider documentation)
- Tools: R/RStudio, tidyverse, ggplot2, lubridate, and a time-series forecasting package

## Important
This is a **planning document**, not a report of completed analysis. Do not claim any results, plots, or accuracy scores until the data have been retrieved and the R scripts have been run. Keep raw and processed data separate, cite the data source, and document cleaning decisions.
